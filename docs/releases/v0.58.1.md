# Autolith 0.58.1

## Checkpoints and Nix

- Fix terminal disconnections during `(checkpoint)`, including controller and observer reconnection without duplicate history ([#83](https://github.com/lambda-symbolics/autolith/issues/83)).
- Check the source before pausing the application, and include checker diagnostics when validation fails.
- Fix packaged Nix checks writing into the read-only store. Use the writable ASDF cache for test-loader locks.
- Record final core paths when publishing Nix images, and fix packaged recovery checkouts and isolated child loading.

## Providers and authentication

- Fix Anthropic requests being rejected because of unsupported root-level tool schema fields.
- Configure OpenRouter provider preferences per model or with a `*` fallback using `:openrouter-provider-routing` or `AUTOLITH_OPENROUTER_PROVIDER_ROUTING`.
- Refresh ChatGPT, Grok, Nous, and Gemini credentials through the shared OAuth refresh grant, with bounded requests and serialized credential updates.

## Lisp and terminal

- Read `self.eval` forms in AUTOLITH and accept internal symbols through single-colon `autolith:` references.
- Render pickers through grouped selector tables.
- Hide the input cursor during startup.

Update with `(update)`.
